# Sirenas 5 anos

Version visual e interactiva del proyecto SIRENAS para alumnado de Infantil 5 anos.

## Uso

Abrir `sirenas-5/index.html` en el navegador. No necesita servidor ni instalacion de dependencias.

## Caracteristicas

- Tarjetas grandes para seleccionar actividades.
- Imagenes del proyecto y miniaturas optimizadas.
- Boton de lectura en voz alta usando `speechSynthesis` del navegador.
- Boton de alto contraste.
- Actividad de comprension lectora con pregunta de opcion multiple.
- Zona sencilla para escribir o dibujar una idea con ayuda.

## Actividades desarrolladas

- Semana 1, actividad 1: lectura de `COCO CARTA PRESENTACIÓN.pdf` y pregunta sobre por que Coco necesita ayuda.
- Semana 1, actividad 2: ficha `que sabemos de sirenas.png` con tres campos editables y descarga como imagen PNG.
- Semana 1, actividad 3: escucha del poema con `poesia-5-anos-a-ana.mp3` y juego memory para unir palabras que riman. Incluye dibujos infantiles en cada ficha y sonido de olas al descubrirlas.

## Mantenimiento

Este proyecto usa recursos de `../content/resources/` y `../content/resources/thumbs/`. Si se mueve de carpeta, hay que actualizar esas rutas relativas.
